# HR-ANALYTICS-DASHBOARD-USING-TABLEAU
This HR analytics project, built using Tableau, provides an interactive dashboard to visualize key human resource metrics. It focuses on employee attrition, job satisfaction, performance, and departmental breakdowns. The project uses charts such as bar graphs, pie charts, and heat maps to present trends in employee behavior and highlight areas where HR can improve retention, performance management, and workforce planning. The visuals allow for easy filtering and comparison across departments, job roles, and tenure levels, supporting data-driven HR decision-making
